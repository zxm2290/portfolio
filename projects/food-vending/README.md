# Local Food Vending System | سامانهٔ محلی فروش غذای دستگاهی

## English

A local software core connecting a customer ordering interface, an admin dashboard, SQLite records, and a Modbus device boundary. A separate simulator exercises order, payment-test, and device-response scenarios. Real payment terminal and physical hardware integration require their own validation.

## فارسی

هستهٔ نرم‌افزاری محلی که رابط سفارش مشتری، داشبورد مدیر، داده‌های SQLite و مرز ارتباط با دستگاه Modbus را به هم وصل می‌کند. شبیه‌ساز جداگانه سناریوهای سفارش، پرداخت آزمایشی و پاسخ دستگاه را بررسی می‌کند. اتصال کارت‌خوان واقعی و سخت‌افزار فیزیکی نیازمند آزمون مستقل است.
