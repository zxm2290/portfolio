# FastAPI Notes API | API یادداشت با فست‌اِی‌پی‌آی

## English

A learning project with a FastAPI CRUD API, SQLite storage, and a simple web interface for notes. It covers request validation, record lookup, creation, editing, and deletion.

## فارسی

پروژهٔ آموزشی شامل API عملیات اصلی یادداشت با FastAPI، ذخیره‌سازی SQLite و رابط وب ساده. اعتبارسنجی درخواست، خواندن رکورد، ایجاد، ویرایش و حذف را پوشش می‌دهد.
