# Medication Companion | سامانهٔ همراه دارو

## English

A React and Node.js medication management system with role-based access, dose tracking, inventory, reports, and caregiver workflows. The web app includes installable PWA and notification features. Real-device Android packaging and delivery behavior need separate verification.

## فارسی

سامانهٔ مدیریت دارو با React و Node.js شامل دسترسی نقش‌محور، ثبت مصرف، موجودی، گزارش و جریان‌های مراقبتی. نسخهٔ وب قابلیت نصب به‌شکل PWA و اعلان دارد. بستهٔ اندروید و رفتار اعلان روی دستگاه واقعی باید جداگانه تأیید شوند.
