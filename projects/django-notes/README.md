# Django Notes App | برنامهٔ یادداشت با جنگو

## English

A small learning project for creating and managing notes with Django, templates, forms, and a database. It demonstrates a conventional server-rendered web workflow.

## فارسی

پروژهٔ آموزشی کوچک برای ساخت و مدیریت یادداشت با Django، قالب‌ها، فرم‌ها و پایگاه داده. جریان معمول یک برنامهٔ وب با رندر سمت سرور را نشان می‌دهد.
