# Academic Society Information Page | صفحهٔ معرفی انجمن علمی

## English

A compact, responsive Persian information page for an academic society. It presents the group, activities, and contact paths in a mobile-friendly layout. A QR asset was prepared for sharing the page.

## فارسی

صفحهٔ فارسی، جمع‌وجور و واکنش‌گرا برای معرفی یک انجمن علمی. معرفی انجمن، فعالیت‌ها و راه‌های ارتباطی را در چیدمان مناسب موبایل نمایش می‌دهد. یک کد QR نیز برای اشتراک صفحه آماده شد.
