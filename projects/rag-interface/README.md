# Persian Document Search Interface | رابط فارسی جست‌وجوی اسناد

## English

Front-end work on a Persian, right-to-left interface for an existing document search and chat system. The contribution covered React screens and API integration while respecting the existing backend contract. This page describes the interface contribution, not ownership of the full system.

## فارسی

کار روی رابط فارسی و راست‌به‌چپ یک سامانهٔ موجود برای جست‌وجو و گفت‌وگو دربارهٔ اسناد. سهم این کار شامل صفحه‌های React و اتصال به API با رعایت قرارداد بک‌اند بود. این معرفی دربارهٔ سهم رابط کاربری است، نه مالکیت کل سامانه.
