# Cafe Menu and Management Dashboard | منوی کافه و داشبورد مدیریت

## English

A customer-facing digital menu and a password-protected management dashboard. The dashboard supports menu items, categories, prices, availability, and images. Menu changes are stored on the server and reflected in the customer view. This project does not include ordering or payment.

## فارسی

منوی دیجیتال مشتری و داشبورد مدیریت با ورود رمزدار. مدیر می‌تواند آیتم‌ها، دسته‌ها، قیمت، موجودی و تصویرها را مدیریت کند. تغییرات در سرور ذخیره می‌شود و در منوی مشتری نمایش می‌یابد. ثبت سفارش و پرداخت جزو این پروژه نیست.
