# Daily Tasks App | برنامهٔ کارهای روزانه

## English

A Django learning application for personal task tracking. Tasks belong to individual users and can be marked complete. The project demonstrates authentication and ownership boundaries in a small web app.

## فارسی

برنامهٔ آموزشی Django برای پیگیری کارهای شخصی. هر کار به کاربر خودش تعلق دارد و می‌توان آن را تکمیل‌شده علامت زد. پروژه ورود کاربران و مرز مالکیت داده را در یک برنامهٔ کوچک نشان می‌دهد.
