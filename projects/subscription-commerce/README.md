# Subscription Commerce and Provisioning | فروش و تأمین اشتراک

## English

Work on a PHP and MySQL ordering flow that connects payment review, a Telegram bot, an admin panel, and subscription provisioning. The description is limited to workflow and integration responsibilities; it includes no customer configuration, service address, credential, or source code.

## فارسی

کار روی جریان سفارش با PHP و MySQL که بررسی پرداخت، ربات تلگرام، پنل مدیریت و تأمین اشتراک را به هم متصل می‌کند. این معرفی فقط مسئولیت‌های جریان کار و یکپارچه‌سازی را بیان می‌کند و هیچ تنظیم مشتری، نشانی سرویس، اطلاعات ورود یا کدی ندارد.
