# Cookie Viz Browser Extension | افزونهٔ مرورگر کوکی‌ویز

## English

A browser extension that visualizes cookies and browser storage, including a first-party versus third-party view. Built with WXT and React for Chrome and Firefox targets. Build output was checked; browser behavior requires its own runtime verification.

## فارسی

افزونه‌ای برای نمایش کوکی‌ها و فضای ذخیره‌سازی مرورگر، همراه با تفکیک داده‌های شخص اول و شخص ثالث. با WXT و React برای هدف‌های Chrome و Firefox ساخته شده است. خروجی ساخت بررسی شده و رفتار در مرورگر نیازمند آزمون اجرایی جداگانه است.
