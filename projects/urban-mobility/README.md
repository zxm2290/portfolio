# Urban Mobility Analytics | تحلیل سفرهای شهری

## English

A data engineering and analytics project for urban trip records. It covers ingestion, cleaning, quality checks, metrics, demand analysis, and an analytical dashboard using PySpark, PostgreSQL, and scheduled workflows. This is an analytical project, not a live transport service.

## فارسی

پروژهٔ مهندسی و تحلیل داده برای رکوردهای سفر شهری. دریافت و پاک‌سازی داده، کنترل کیفیت، شاخص‌ها، تحلیل تقاضا و داشبورد تحلیلی با PySpark، PostgreSQL و گردش‌کارهای زمان‌بندی‌شده را پوشش می‌دهد. این پروژه تحلیلی است و سرویس حمل‌ونقل عملیاتی نیست.
