# Industrial Services Showcase | وب‌سایت معرفی خدمات صنعتی

## English

A Persian, right-to-left industrial showcase built with React, TypeScript, and Three.js. It presents services and a collaboration process through a responsive interface. This description omits client identity, operational details, and deployment access.

## فارسی

وب‌سایت فارسی و راست‌به‌چپ برای معرفی خدمات صنعتی، ساخته‌شده با React، TypeScript و Three.js. رابط واکنش‌گرا توانمندی‌ها و روند همکاری را معرفی می‌کند. نام مشتری، جزئیات عملیاتی و دسترسی استقرار در این معرفی نیامده است.
