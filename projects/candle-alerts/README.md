# Chart-Based Candle Alerts | هشدار کندل بر پایهٔ نمودار

## English

A local dashboard for drawing price zones on charts and receiving Telegram alerts when monitored candles meet defined conditions. It tracks selected time frames and avoids duplicate alerts. The current application is for alerts; it does not place trades.

## فارسی

داشبورد محلی برای رسم ناحیه روی نمودار و دریافت هشدار تلگرام هنگام برقرار شدن شرط‌های کندل. تایم‌فریم‌های انتخابی را پایش می‌کند و از هشدار تکراری جلوگیری می‌کند. نسخهٔ فعلی فقط هشدار می‌دهد و معامله ثبت نمی‌کند.
