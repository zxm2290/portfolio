# Private Network Operations | عملیات شبکهٔ خصوصی

## English

Connectivity diagnosis and migration work for a multi-node private network. The work focused on service health, authenticated connections, end-to-end traffic checks, and careful change control. Infrastructure identifiers, topology, and customer settings are intentionally omitted.

## فارسی

عیب‌یابی ارتباط و جابه‌جایی مسیر در یک شبکهٔ خصوصی چندگرهی. بررسی سلامت سرویس، اتصال‌های احراز‌شده، ترافیک سرتاسری و تغییرات کنترل‌شده محور کار بود. شناسه‌های زیرساخت، ساختار شبکه و تنظیمات مشتری عمداً حذف شده‌اند.
